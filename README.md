Implementación y Evaluación de Filtros Digitales
Descripción
Este proyecto consiste en el diseño e implementación de filtros digitales utilizando Python para el procesamiento de señales.

Se implementaron:

Filtro pasa bajos
Filtro pasa altos
Filtro pasa bandas
Objetivo
Analizar el comportamiento de diferentes filtros digitales mediante señales de prueba con ruido y comparar los resultados obtenidos después del filtrado.

Herramientas utilizadas
Python
NumPy
SciPy
Matplotlib
Archivos
filtros_digitales.py
README.md
Resultados
Los filtros demostraron ser efectivos para eliminar ruido y seleccionar componentes específicas de frecuencia.
